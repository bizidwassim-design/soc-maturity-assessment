# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed
- A partial assessment is flagged next to the level and in amber, with the number of unanswered questions and untouched domains, because unanswered questions are excluded from the mean.

### Changed
- The first visit opens on the fictional sample, with a banner and a *Start with a blank assessment* button that is remembered, so visitors see real-looking results straight away.

## [1.0.0] — 2026-10-31

### Added
- Initial public release.
- Single-page assessment app (`index.html`, `assets/`, `data/questions.js`): 50 questions, 6 domains, 5 levels,
  live domain and overall scores, inline-SVG radar chart, top-10 gap table with next steps, JSON export and import,
  print stylesheet, local draft in `localStorage`, light and dark themes, strict CSP, no external resources.
- Fictional "Northwind Logistics" sample (`data/sample.js`, `examples/northwind-sample.json`, `?sample=1`).
- Question bank as CSV (`data/questions.csv`) generated by `scripts/build_data.js`.
- `docs/maturity-model.md` (level definitions and evidence per domain) and `docs/using-the-results.md`
  (building a 12-month roadmap from the gaps).
- CI: syntax check of all scripts, structural checks of the question bank, generated-file freshness, `html-validate`.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, Dependabot for GitHub Actions.
